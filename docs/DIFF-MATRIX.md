## 一、七条差异化种子（Issue #44，M1 定稿）

1. **滴度 PR3/MPO 分列**（无判定列）：靶抗原不同、语义不同，不能合成一条"ANCA 滴度"。
2. **复发事件独立档案**（非肿瘤 `recurrence` 语义）：日期 / 受累器官 / 确认依据原文 / 科室；不复用肿瘤命名。
3. **免疫抑制剂量版本链**：环磷酰胺 / 利妥昔单抗 / 霉酚酸酯 / 激素；开始、暂停、停用、换用都留痕；化验联动只做并列语境。
4. **激素副作用分节不进趋势**：骨与关节 / 糖代谢 / 感染 / 眼与其他；分类副作用不画进滴度曲线。
5. **双主体代记**：患者本人 + 家属照护者；活动期口述事实记录，`recorder` 标识；private 分级。
6. **长程多科随访、零停药暗示**：肾科 / 风湿科 / 呼吸科复诊节奏语境；免疫抑制减量是高风险决策域。
7. **肾活检病理语境引用不判定**：报告原文 + 术语卡，不做病理分级、不给严重度、不判断诊断。

> 第 8 条（M1 新增，作为第 7 条的边界补充）：**急症红旗只做固定通用提示**，不根据用户数据触发判断、不做分诊评分。

## 五、与对照仓的刻意差异（G1 说明用）

| 对照仓 | 它怎么做 | 本仓为什么不同 |
| --- | --- | --- |
| breast | 肿瘤标志物 + 影像 + 治疗历程 | ANCA 无"肿瘤负荷"概念；核心是滴度/肾功双轨 + 复发事件，故不做 `tumor` 线 |
| acromegaly | 生化时间线（GH/IGF-1）+ 激素替代 | 同为"数值主线"，但 ANCA 必须把 PR3 与 MPO 分列，且滴度与肾功分轨；激素在本仓是治疗药，不是替代 |
| attr | 心脏/神经按器官分线 | ANCA 的器官受累是**事件属性**，不单独成一级线；用复发事件档案 + 受累器官字段承接 |
| liver | 我的肝 / 我的瘤双轨 | ANCA 无"双轨器官"；改为滴度/肾功双轨 + 病理影像独立线 |
| thyroid | 随访与调药合并 | ANCA 把治疗版本链与随访日历分开：用药变更需要版本链，复诊节奏是日程 |

## 六、G1 决策点（6 条，详见 family-landscape §6.6）

1. 滴度与肾功时间线：一条一级、内部三轨（推荐）vs 拆两条；
2. 复发事件：独立一级（推荐）vs 挂随访日历；
3. 激素副作用分节：独立一级（推荐）vs 挂治疗与用药；
4. 病理与影像：独立一级（推荐）vs 挂病情整理；
5. 是否保留病情整理 + 病情一图秀：都保留（推荐）/ 删一图秀 / 都删；
6. 临床研究入口：复诊与资料二级（推荐）vs 独立一级。
