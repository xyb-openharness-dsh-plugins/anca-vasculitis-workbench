## 一、总原则

- AI 默认：说 / 拍化验单 / 交 PDF → 结构化候选 → 逐项核对 → 确认才入事实层；拒收零副作用。
- 手工永远可及但收敛：「⋯ 更多」收口；每页显式编辑 ≤1；表单 ≤6 字段；数字用键盘组件。
- 删除 = 更正：只新增版本；界面语言"改这一条"，全站无"不可恢复"。
- 回首页一步：二级页返回 / 顶栏「小脉宝」/ 完成 Toast 内嵌「回到看板」。
- **红线**：不生成"复发/缓解/活动"判定；不把滴度回升写成复发预告；不做病理分级/诊断判断；零"建议调整/可以停药"；急症提示固定通用、不判分诊。

| 生育/妊娠计划 | **—** | 只做私密记录与"与医生讨论"提示 | 红线：不给生育/妊娠建议 |

## 六、34 号 · AI 协助一键发送（继承，不另写）

| 段 | 谁 | 做法 |
| --- | --- | --- |
| 1 入口 | 业务页 | `<a href="anca:agent-draft?prompt=…">`；点击 `preventDefault` |
| 2 发送 | 业务页 | 嵌入式 → `postMessage({type:'anca:agent-draft', prompt, send:true}, location.origin)`；独立打开 → 本地演示面板 + "未接通"说明，不假装发送 |
| 3 送达 | 壳层 | 校验 `event.source` 与 `event.origin`；prompt 截断 ≤8000；`rememberDraft` 持久队列 |
| 4 填发 | 壳层 | `input.setDraft()` → 仅 `phase==='plain'` 且草稿非空才 `submit()`；双守卫 |

红线：发送内容 = 预写提示词 + **已确认**病情上下文；private 默认不进上下文；AI 回复仍是候选，核对才入事实层。

## 七、35 号 · 试验匹配三态（继承）

- 入口：复诊与资料 → `reports` 二级的"临床研究"入口（不独立一级）。
- 三态：**命中**（结构化/文本/宽口径 + 证据原文）/ **无法自动匹配**（逐条列原因）/ **不产出"不适用"**。
- 固定标注：来源通道与终态（SUCCESS/FAILED）、snapshotDate、"登记状态，未核实"、登记 ≠ 有效 ≠ 可入组。
- 禁止：`match_score`、`eligible`、`suitability` 列；数值化匹配度；隐藏命中证据。
