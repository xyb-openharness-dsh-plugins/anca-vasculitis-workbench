## 三、G4 定义（摘要）

1. **手工通道**：9 类可写实体的手工新增 / 更新 / 更正逐项实测（每页编辑入口 ≤1、表单 ≤6 字段、数字键盘、无裸删除）。
2. **AI 通道**：候选 → 逐项核对 → 确认入库；拒收零副作用；AI 回复是候选不是事实。
3. **同源断言**：两通道写同一事实层、同一版本链（IP9）；更正后旧版本可查；全站无"不可恢复"。
4. **隐私**：private 三出口（界面/导出/Agent 上下文）在两条通道下都过滤。
5. **时机与效力**：M5 出口在开发版首过（V1 已过之后）；未过不进 M6 装机；M6 真机 V3 复跑抽查两条核心链。
